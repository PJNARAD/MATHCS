# MATHCS — Mathematics for Computer Science

Interactive mathematics laboratory for CS students. Built with React + Vite + TypeScript.

## Deploy

This app uses client-side routing. SPA rewrites are configured via `vercel.json` and `netlify.toml` so deep links like `/concept/rsa` work after refresh on static hosts.

## Scripts

- `npm run dev` — dev server
- `npm run build` — production build
- `npm run typecheck` — type checking
- `npm test` — run tests
- `npm run verify` — typecheck + tests + snippet verification + index freshness + SSR smoke
- `npm run audit` — content coverage report (depth, gaps, dangling references)
- `npm run audit:json` — the same report as JSON
- `npm run index:write` — regenerate `src/data/concept-index.ts` (the shipped,
  content-free concept index) after a content change
- `node scripts/route-size.mjs` — after a build, what each route downloads and
  whether it can reach a lesson body

## Content

- [`CONTENT-ROADMAP.md`](CONTENT-ROADMAP.md) — what is published, what is
  missing, and what to write next, with the audit numbers behind each claim.
- `src/data/concepts/` — one file per domain (or domain group); every lesson is
  typed content: blocks, prerequisites, cross-links and practice questions.
- `src/data/snippets.ts` — runnable playground snippets. Declared outputs are
  generated by execution (`npm run snippets:write`) and checked in CI.
- `src/data/concept-index.ts` — **generated**: id, title, domain, level, summary
  and links for every concept, with no lesson content. Link components, search,
  the command palette and the domain/path/home pages read this, so no route
  downloads lesson bodies.
- `src/lib/concept-loader.ts` — the lazy content path. `readConcept(id)` returns
  the lesson, suspending (React Suspense) while the domain's chunk loads;
  `loadConcept(id)` is the promise form. Each domain is one dynamic `import()`,
  so a concept page fetches a single domain chunk. `src/lib/concepts.ts` remains
  the static registry, used by the tests and scripts only — a guard test fails if
  any shipped module imports it.
