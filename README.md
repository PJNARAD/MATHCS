# MATHCS — Mathematics for Computer Science

Interactive mathematics laboratory for CS students. Built with React + Vite + TypeScript.

## Deploy

This app uses client-side routing. SPA rewrites are configured via `vercel.json` and `netlify.toml` so deep links like `/concept/rsa` work after refresh on static hosts.

## Scripts

- `npm run dev` — dev server
- `npm run build` — production build
- `npm run typecheck` — type checking
- `npm test` — run tests
- `npm run verify` — typecheck + tests + snippet verification + SSR smoke
- `npm run audit` — content coverage report (depth, gaps, dangling references)
- `npm run audit:json` — the same report as JSON

## Content

- [`CONTENT-ROADMAP.md`](CONTENT-ROADMAP.md) — what is published, what is
  missing, and what to write next, with the audit numbers behind each claim.
- `src/data/concepts/` — one file per domain (or domain group); every lesson is
  typed content: blocks, prerequisites, cross-links and practice questions.
- `src/data/snippets.ts` — runnable playground snippets. Declared outputs are
  generated by execution (`npm run snippets:write`) and checked in CI.

## Branches
